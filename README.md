# SkyDancer Productions — Website

Luxury event entertainment website for **SkyDancer Productions** (Miami, FL) — professional dancers, Hora Loca, LED robots, fire performers, live musicians and custom productions.

Sitio web de entretenimiento de lujo para **SkyDancer Productions** (Miami, FL).

## ✨ Features / Características

- **Fullscreen video banner** home with a 3D animated logo.
- **Bilingual EN / ES** toggle.
- **Editorial menu** — full-screen founder panel (Liana del Toro) with an AI-animated portrait, brand monogram and numbered navigation.
- **Views**: About the Company (with expandable "Our Experience"), Services & Pricing (store-style with per-service product modal, photo + description + price), Gallery & Artists, Contact & Booking.
- **Quote cart** — add/remove services, automatic multi-service discounts (2 → 5%, 3+ → 10%), clear-all, and one-tap request via WhatsApp or email.
- **Fully responsive** and mobile-optimized.

## 🚀 How to view / Cómo ver

- **Locally:** open `index.html` in any modern browser.
- **Live (GitHub Pages):** enable *Settings → Pages → Deploy from branch → main / root*. The site will be served at `https://<user>.github.io/<repo>/`.

## 📁 Structure / Estructura

```
index.html                     Single-file site (HTML + CSS + JS)
assets/
  liana-founder.jpg            Founder photo
  liana-founder.mp4            Founder — animated portrait
  liana-hero.mp4              Founder — full-length editorial (menu panel)
  services/                    Drop per-service photos here: dancers.jpg, gogo.jpg, ...
video banner/
  skydancer-web.mp4            Optimized banner video (used by the site)
```

> To feature real service photos, add images named by service id inside `assets/services/`
> (`dancers.jpg, gogo.jpg, greeters.jpg, robot.jpg, fire.jpg, sax.jpg, drummer.jpg, champagne.jpg, horaloca.jpg, choreo.jpg, themed.jpg, interactive.jpg, photobooth.jpg, custom.jpg, coord.jpg`).
